# TRAIN STOP CHALLENGE — Achievement Modifier

TRAIN STOP CHALLENGE専用の実績解除状態編集ツールです。ゲーム本体から発行した引き継ぎコードを読み込み、30種類の実績の解除状態を編集し、ゲーム本体で再び読み込める引き継ぎコードを発行します。

**最新ツールバージョン：v1.4.0**

## 公開ページ
https://mylifereading6666-oss.github.io/Web-based-Train-Modification-Tool/

## 対象ゲーム
https://mylifereading6666-oss.github.io/train-stop-challenge/

## 使い方
1. TRAIN STOP CHALLENGEを開き、「データ引き継ぎ」から引き継ぎコードを発行します。
2. このツールに `TS1.` で始まるコードを貼り付け、検証して読み込みます。
3. 解除したい実績を選択して解除するか、「全30種類を解除」を使用します。
4. 「変更したデータを引き継ぎコードにする」を押します。
5. ゲーム本体の「データ引き継ぎ」で新しいコードを確認し、復元します。

## 変更するデータ
- 実績ID 0〜29 の解除日時のみを編集します。
- 既に解除済みの実績の日付は、解除状態を維持する限り保持します。
- プレイ回数、スコア、停車記録、設定などは変更しません。
- 解除状態を編集した後は、ゲーム本体で新しいコードを復元する必要があります。
- ツールが出力する引き継ぎコードには専用認証情報 `TSC-MODIFIER-AUTH-V1` を付与します。
- ゲーム本体は、この専用認証情報があるコードだけ実績解除条件チェックをスキップします。ゲーム本体から通常発行したコードには付与されません。

## ローカルパスワード認証（v1.2.0）
- 初回起動時に、このブラウザ専用のパスワードを設定します（14文字以上）。
- パスワード本文は保存せず、ランダムソルトとPBKDF2-HMAC-SHA-256（600,000回）の検証値のみをブラウザのlocalStorageに保存します。
- 認証後10分間操作がない場合、または別アプリへ切り替えてページが非表示になった場合は自動ロックします。
- ロック時は読み込み済みデータと入力コードを画面・メモリ上から消去します。再度使うにはパスワード入力が必要です。
- パスワードはブラウザ・端末ごとに別々です。別端末では新規設定が必要です。忘れた場合は当該サイトのブラウザ保存データを消去して再設定します。
- **重要：** サーバーなしのため、これは同じブラウザを使う人へのローカルなアクセス制限です。公開JavaScriptを解析・改変できる人に対する完全な利用制限や、管理者だけに利用を許可する認証ではありません。サーバーなしでこの制約を解消することはできません。

## コード入力の改善（v1.4.0）
- コード前後の空白・改行・UTF-8 BOM・Markdownコードフェンスを含む入力を整理して読み込みます。
- コード形式の不一致とAES-GCM復号失敗を別のエラーメッセージで案内します。

## サーバーなしの仕組み
- サーバー、データベース、ログイン、外部APIは使用しません。
- 引き継ぎコードの復号・編集・再暗号化はブラウザ内で処理します。
- ゲームと同じ `TS1.secret.iv.ciphertext` 形式、AES-256-GCMを使用します。
- 新しいコードはゲーム本体の既存の引き継ぎ機能で読み込めます。
- 入力したコードやセーブデータを外部へ送信しません。
- HTTPSで開いてください（Web Crypto APIが必要です）。

## 注意
- 引き継ぎコードには復元に必要な秘密情報が含まれます。第三者に共有しないでください。
- このツールは実績の保存状態を編集します。実際のプレイ履歴やスコアは増やしません。
- 復元前にゲーム本体のデータをバックアップすることをおすすめします。
- ゲーム本体のリポジトリ・ウェブサイトは変更しません。このリポジトリだけで動作します。

## ローカル起動
HTTPSまたはlocalhostで配信してください。例：
```bash
python -m http.server 8000
```
その後、ブラウザで `http://localhost:8000/` を開きます。
